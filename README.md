# support-control

نظام الدعم الفني والمخازن — أكاديمية السلطان قابوس لعلوم الشرطة.

| المسار | المحتوى |
|---|---|
| `src/index.html` | الواجهة كملف واحد (المصدر الذي تُعدّله) |
| `src/api/api.php` | خادم المزامنة (PHP + MySQL) |
| `tools/build.py` | يفصل الملف الواحد إلى ملفات قابلة للتخزين المؤقت في `dist/` |
| `dist/` | نسخة النشر الجاهزة: تُنسخ إلى `htdocs` (مع `api/config.php` الخاص بك) |
| `docs/AUDIT.md` | تقرير الفحص الشامل: أسباب البطء، الأخطاء المُصلحة، والتوصيات |

بعد أي تعديل على `src/`:

```
python tools/build.py
```
