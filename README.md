# Support Control — أكاديمية الاختراق الأخلاقي

منصّة تعليمية متخصّصة في **الاختراق الأخلاقي والأمن الهجومي**، مصمّمة لتأخذ المتعلّم من الصفر إلى الاحتراف عبر مسار متدرّج، دروس مفصّلة، مكتبة أدوات، ومعامل تطبيقية — ضمن إطار أخلاقي وقانوني صارم.

> ⚖️ **تعهّد أخلاقي:** كل محتوى هذه المنصّة مخصّص للاختبار المصرّح به قانونيًا والدفاع السيبراني. اختبار أي نظام لا تملكه دون تفويض مكتوب جريمة. المنصّة تُعلّم المهارة والمسؤولية معًا، ولا تقدّم أي استغلال موجّه ضد أهداف حقيقية.

## المميّزات

- **منهج من 11 مرحلة** — من الأساسيات التقنية (شبكات، لينُكس، برمجة) حتى كتابة التقارير والشهادات العالمية.
- **19+ درسًا مفصّلًا** — كل درس يتضمّن أهدافًا تعليمية، فيديو، فهرسًا تلقائيًا، ومحتوى مرجعيًا.
- **مكتبة أدوات** — تعريف أشهر أدوات الأمن الهجومي، فئاتها، ومجال استخدامها المصرّح به.
- **معامل وتمارين** — روابط منصّات التدريب القانونية ودليل بناء معمل منزلي معزول.
- **خريطة شهادات ومسار مهني** — من المبتدئ إلى الخبير.
- **تصميم احترافي** — واجهة عربية (RTL)، وضع داكن، نظام تصميم متكامل، ومتجاوب مع الجوال.

## البنية التقنية

**تطبيق صفحة واحدة (SPA) مدمج في ملف `index.html` مستقل.** كل CSS وJavaScript والمحتوى مدمج داخل الملف، فيعمل **بالنقر المزدوج مباشرة** دون أي خادم أو ملفات خارجية.

```
support-control/
├── index.html            # ★ الملف المستقل الجاهز (افتحه مباشرة)
├── build.js              # سكربت يعيد توليد index.html من المصادر
└── assets/               # المصادر القابلة للتعديل
    ├── css/styles.css    # نظام التصميم الكامل
    └── js/
        ├── icons.js      # مجموعة أيقونات SVG
        ├── data.js       # طبقة المحتوى (المنهج/الدروس/الأدوات)
        └── spa.js        # موجّه التطبيق (SPA) ومنطق العرض
```

### التشغيل

افتح **`index.html`** بالنقر المزدوج — هذا كل شيء. يعمل كملف واحد عبر `file://` بلا خادم.

> الخطوط من Google Fonts تحتاج اتصالًا بالإنترنت لتظهر بأفضل شكل؛ وبدونه يرجع التصميم تلقائيًا لخط النظام دون أن ينكسر.

### إعادة البناء بعد تعديل المحتوى

```bash
node build.js    # يقرأ assets/ ويعيد توليد index.html المستقل
```

كل المحتوى يُقاد من `assets/js/data.js` — لإضافة درس أو أداة، عدّل هذا الملف ثم شغّل `node build.js`.

### التوجيه الداخلي (SPA)

| الصفحة | المسار |
|--------|--------|
| الرئيسية | `#/` |
| المنهج | `#/curriculum` |
| الدروس | `#/lessons` |
| درس محدّد | `#/lesson/<id>` |
| الأدوات | `#/tools` |
| المعامل | `#/labs` |
| الشهادات | `#/certs` |

## إضافة درس جديد

في `assets/js/data.js` أضف مدخلًا إلى `window.LESSONS` بالصيغة:

```js
"l-newid": {
  phase: "p2", num: "2.3", level: "inter", minutes: 40, icon: "radar",
  title: "عنوان الدرس",
  desc: "وصف مختصر.",
  objectives: ["هدف 1", "هدف 2"],
  video: "عنوان الفيديو — المدة",
  content: [
    { id: "sec1", h: "عنوان القسم", body: `<p>محتوى HTML…</p>` }
  ],
}
```

ثم أضف `l-newid` إلى مصفوفة `lessons` في المرحلة المناسبة ضمن `window.CURRICULUM`، وأخيرًا شغّل `node build.js` لإعادة توليد الملف المستقل.
